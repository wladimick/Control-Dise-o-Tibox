# Tareas diarias

1. Ejecutar `supabase/migrations/20260721_daily_tasks.sql` en Supabase SQL Editor.
2. La página `/tareas-diarias` separa la bitácora en pestañas Wladimick y Braulio.
3. Cada pestaña mantiene sus propias columnas visibles en `localStorage`.
4. Las tareas pueden quedar sin asociar o vincularse a un trabajo principal.
5. Las HH diarias son horas reales ejecutadas y no reemplazan las HH estimadas del trabajo principal.
